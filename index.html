How I think / How I make

Good design starts
with better questions.

01

Understand first.

Start with the people, the context, and the friction. Frame the right problem before reaching for a solution.

Questions / Journeys / Opportunity
02

Make it tangible.

Turn possibilities into flows and prototypes. Explore broadly, then make the trade-offs visible.

Flows / Prototypes / Feedback
03

Refine with purpose.

Test the idea, question the details, and build a consistent system. Keep what helps. Remove what doesn’t.

Iteration / Systems / Handoff
